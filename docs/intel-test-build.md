# Тестовая сборка OpenEmu для Intel

Это Release-сборка для 64-битных Intel Mac, а не официальный нотарифицированный
релиз. Xcode для запуска не нужен. Все 28 поддерживаемых ядер находятся внутри
`OpenEmu.app`. ROM и BIOS в архив не входят.

## Как запустить

1. Распакуйте ZIP и оставьте всю папку `OpenEmu-Intel-test` в удобном месте.
2. Закройте другую запущенную копию OpenEmu, если она есть.
3. Откройте `OpenEmu.app`. При первом запуске пройдите мастер настройки.
4. Импортируйте свою игру и проверьте изображение, звук и управление.

Не заменяйте установленный OpenEmu для первого теста. Если у вас уже есть
библиотека, сначала сделайте её резервную копию. Чтобы выбрать или создать
отдельную тестовую библиотеку, удерживайте Option при запуске. Выбор библиотеки
сохраняется в настройках: старую можно снова выбрать таким же способом.

## Что важно знать

- Сборка подписана локальной ad-hoc подписью, но не имеет Developer ID и
  нотарификации Apple. macOS может потребовать вручную разрешить её открытие
  в «Системные настройки → Конфиденциальность и безопасность». Не отключайте
  Gatekeeper для всей системы.
- Программа использует обычные настройки OpenEmu. Сам архив ничего не
  устанавливает, но запуск приложения может обновить существующие RetroArch
  bridge-плагины. Отдельная библиотека не изолирует все настройки и ядра.
- Ранее установленные ядра в `~/Library/Application Support/OpenEmu/Cores/`
  имеют приоритет над одноимёнными встроенными ядрами. Если такое ядро уже
  установлено, игра может использовать именно его. Не удаляйте свои ядра и
  сохранения ради теста: перед заменой нужна резервная копия.
- Google Drive и ScreenScraper используют пустые шаблонные учётные данные;
  соответствующие интеграции не настроены в этой тестовой сборке.
- Некоторым системам нужны ваши BIOS. MAME использует набор ROM, совместимый
  с версией 0.250. Для Nintendo 64 на Intel используется более медленный
  интерпретатор вместо динамической перекомпиляции.
- Успешная сборка и проверка запуска не гарантируют совместимость каждой игры.

Точный коммит указан в `BUILD-INFO.txt`. Исходный код и лицензии:
[communism420/OpenEmu-Intel](https://github.com/communism420/OpenEmu-Intel).
Сборка предназначена для бесплатного тестирования; в том числе Picodrive нельзя
использовать в коммерческой сборке.
