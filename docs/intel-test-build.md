# Тестовая сборка OpenEmu Reborn для Intel

Это памятка для тестовой Release-сборки с поддержкой 64-битных Intel Mac,
а не официального нотарифицированного релиза. Xcode для запуска не нужен.
Все 28 поддерживаемых ядер находятся внутри
`OpenEmu.app`. ROM и BIOS в архив не входят.

OpenEmu Reborn — независимое фанатское продолжение на основе OpenEmu-Silicon.
`1.0.0` начала новую линейку версий приложения; текущие исходники готовят
`1.0.1` (сборка 24). Это не версии ядер. Публичный релиз `1.0.0` уже доступен,
но подготовка исходников `1.0.1` ещё не означает публикацию нового релиза.
Исходники рассчитаны на Intel `x86_64` и Apple Silicon `arm64`. Конкретный пакет
может быть Intel-only или universal: проверяйте `BUILD-INFO.txt` и состав
исполняемых файлов, а не название папки. Технические имена `OpenEmu-Intel-test`
и `OpenEmu.app` сохраняются. Результаты сборки и проверки конкретной ревизии
приведены в соответствующем PR. См. [границы проекта](project-identity.md).

## Как запустить

1. Распакуйте ZIP и оставьте всю папку `OpenEmu-Intel-test` в удобном месте.
2. Закройте другую запущенную копию OpenEmu, если она есть.
3. Откройте `OpenEmu.app`. Если папка данных ещё не выбрана, создайте или выберите
   отдельную пустую папку, затем пройдите мастер настройки. Не выбирайте целиком
   «Документы» или «Загрузки». Отмена выбора закрывает приложение.
4. Импортируйте свою игру и проверьте изображение, звук и управление.

Не заменяйте установленный OpenEmu для первого теста. Если у вас уже есть
данные OpenEmu, сначала сделайте их резервную копию. Обычные запуски используют
ранее выбранную папку, в том числе при переключении между Debug и Release.
Для отдельного теста создайте новую пустую папку и запустите приложение так,
подставив полные пути к приложению и этой папке:

```bash
open "/полный/путь/OpenEmu-Intel-test/OpenEmu.app" \
  --args --data-folder "/полный/путь/OpenEmu Test Data"
```

Такой запуск не меняет папку, запомненную для обычных запусков, и не импортирует
старые настройки или установленные ядра. Выбор другой библиотеки через Option
не заменяет выбор общей папки данных.

## Что важно знать

- Режим подписи (ad-hoc или выбранный сертификат) указан в `BUILD-INFO.txt`.
  Тестовая сборка не имеет нотарификации Apple. Самоподписанный сертификат
  не гарантирует, что другой Mac разрешит её запуск. macOS может потребовать
  вручную разрешить открытие в «Системные настройки → Конфиденциальность и
  безопасность». Не отключайте Gatekeeper для всей системы.
- При подписи сертификатом в приложение входит только открытый сертификат;
  закрытый ключ издателя в сборку не попадает и для запуска не нужен. Локальное доверие к
  сертификату на компьютере издателя не переносится вместе с приложением.
  Создание или импорт сертификата не является обычным шагом установки.
  Разрешение «Мониторинг ввода» выдаётся отдельно на вашем Mac; постоянная
  подпись не выдаёт его автоматически и не гарантирует сохранение разрешения.
- Настройки OpenEmu находятся в `Settings.plist` выбранной папки. Там же по
  умолчанию хранятся библиотека, BIOS, сохранения, установленные ядра, рабочие
  файлы и журналы. Явно выбранные внешние пути остаются внешними. Разрешения
  macOS, небольшой указатель на папку, системные журналы и данные AppKit/Sparkle
  остаются под управлением системы: это не режим «без следов».
- Сохраняйте скрытый файл `.openemu-data-folder.plist` вместе с данными.
  Если диск недоступен, подключите его или укажите ту же папку в окне
  восстановления; другая папка не подменит её автоматически. Перед переносом
  папки закройте OpenEmu.
- Установленные ядра в `<выбранная папка>/Cores/` имеют приоритет над
  одноимёнными встроенными ядрами. Новая пустая папка не подхватывает ядра из
  старого `~/Library/Application Support/OpenEmu/Cores/`. При выборе старой
  папки её ядра сохраняются, а RetroArch bridge-плагины могут обновиться при
  запуске. Обнаруженные ядра перечислены в `Logs/core-inventory.txt`;
  этот список сам по себе не подтверждает запуск игры или путь к исполняемому файлу.
  Не удаляйте свои ядра и сохранения ради теста: перед заменой нужна копия.
- Google Drive и ScreenScraper используют пустые шаблонные учётные данные;
  соответствующие интеграции не настроены в этой тестовой сборке.
- Некоторым системам нужны ваши BIOS. Для MAME нужен набор ROM, совместимый
  с упакованной версией ядра; её можно посмотреть в сведениях о ядре.
  Для Nintendo 64 на Intel используется более медленный
  интерпретатор вместо динамической перекомпиляции.
- Успешная сборка и проверка запуска не гарантируют совместимость каждой игры.

Все 28 встроенных ядер в свежем CI-архиве собраны из одной исходной ревизии.
«Свежесобраны» не означает «обновлены до последних версий эмуляторов»;
восстановление старой CI-сборки сохраняет её старую исходную ревизию.

В `BUILD-INFO.txt` указаны HEAD и наличие локальных изменений в папке упаковки;
они сами по себе не подтверждают исходную ревизию заранее собранных файлов.
Полная памятка — `docs/data-folder.md`. Исходный код и лицензии:
[communism420/OpenEmu-Reborn](https://github.com/communism420/OpenEmu-Reborn).
Сборка предназначена для бесплатного тестирования; в том числе Picodrive нельзя
использовать в коммерческой сборке.
